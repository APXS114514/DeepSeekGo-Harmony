# 未来规划

[English](ROADMAP.en.md)

以下功能大致按顺序推进，尚未排定版本，计划可能调整。

1. **搜索历史对话**：按标题或内容找回以前的对话。
2. **本机朗读**：用系统语音离线朗读回答，不走 API，出声更快，可与现有的 API 音色二选一。
3. **分享出去**：把一条回答或整段对话以文字、Markdown 或长图分享到其他应用，与「分享到 Deepseek GO」一进一出。
4. **无障碍**：补齐屏幕朗读所需的按钮名称和焦点顺序，并检查高对比度下的可读性。
5. **桌面服务卡片**：从桌面一键开始提问，或直接打开最近的对话。
6. **拖拽**：在平板分屏或 2in1 上把文字、图片和文件拖进输入框，也能把回答拖到其他应用。
7. **折叠屏悬停**：半折叠立在桌上时，上半屏显示回答，下半屏输入。
8. **跨设备接续**：手机上聊到一半，在平板或电脑上接着聊，草稿一并带过去。

已发布的功能见 [功能说明](FEATURES.md)，各版本的变化见 [更新日志](CHANGELOG.md)。
