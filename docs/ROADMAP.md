## 鸿蒙专属特性

- **扩展沉浸光感**。为原生顶栏按钮补充按压形变、流光与系统图标动效；在支持的设备上，将网页长按或右键菜单、附件与工具入口半模态以及删除、清空等确认弹窗原生化，获得系统级沉浸光感材质，并补齐网页侧悬浮按钮和胶囊开关的视觉光感。不支持系统材质的设备沿用普通样式。
- **桌面长按快捷方式**。长按桌面应用图标即可直达新对话、语音提问、识别图片文字或无痕对话。
- **系统触感反馈**。在按住说话、上滑取消、流式回答首字到达、深度思考完成、复制成功和菜单弹出等交互节点提供细腻的系统预置触感，并遵循系统触感设置。
- **多页文档扫描**。接入鸿蒙文档扫描能力，支持多页拍摄纸质文档并自动切边、纠偏和去阴影，直接以清晰图片或 PDF 附件发给模型，完整保留表格、公式与版面。
- **后台朗读与播控中心**。将回答朗读接入系统播控中心，切到后台或锁屏后可继续收听长回答，并支持在控制中心、锁屏界面和耳机上暂停或继续。
- **桌面服务卡片**。提供 2×2 快捷入口卡片（新对话、语音、识字、扫文档）与 4×2 卡片（快捷入口及最近对话直达），并在支持的系统上适配通透卡片质感。
- **跨设备拍照与扫文档**。在平板或 2in1 上添加附件时，可直接调用同一华为账号下附近手机的相机拍照、扫文档或选取手机图库图片，拍摄后自动插进当前草稿。
- **碰一碰与隔空传送**。在回答或分享预览页支持两台鸿蒙设备碰一碰或隔空手势，快速将纯文本、Markdown 或长图分享到另一台设备。
- **智感握姿单手适配**。在支持握姿感知的设备上识别左手或右手单手握持，动态将回到底部、语音等高频单手操作调整到更顺手的一侧。

## 模型服务商

- **接入第三方模型 API**。保留 DeepSeek 官方 API，支持在设置中添加硅基流动、腾讯云 TokenHub 和自定义 OpenAI 兼容接口，逐步适配阿里云百炼、OpenAI、Gemini、OpenRouter 和 Claude 等服务。各连接的 API Key 分开保存在鸿蒙 Asset Store，聊天时可选择服务商和模型。联网搜索、图片、文件和语音按服务商及模型提供的能力适配。

## 对话管理

- **撤回上一轮**。撤回最后一条提问及对应回答，正在生成时先停止生成。提问和附件恢复为可编辑的草稿，该轮从本机对话和后续请求的上下文中移除。服务商已收到的请求按其规则处理。
- **从此处开启新分支**。从选中的回答创建独立对话，带上当前路径中从开头到该回答的记录。侧栏新增并打开 `对话（1）`、`对话（2）` 等分支，原对话和各分支可以独立继续、重命名和删除。
- **自动归组分支对话**。首次创建分支时，侧栏将原对话和分支放入同一个可折叠的对话组，并展开该组。分支再开分支时仍归入同组。普通新对话照常单独显示，删除原对话后，其分支仍可使用。

已支持的功能见 [功能说明](FEATURES.md)，各版本的变化见 [更新日志](CHANGELOG.md)。
