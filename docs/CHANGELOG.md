# Deepseek GO 更新日志

## 1.7.0 — 定位、本地信息与图表

- 「通用设置 → 位置信息」由手动选择地区改为按需模糊定位开关；开启后仅在前台处理「我这里」「附近」等本地问题时获取并仅发送城市和行政区。
- 支持结合城市和当地日期自动查询天气、活动与营业时间，逐日天气优先使用 Open-Meteo 结构化数据，其余场景或接口不可用时自动联网搜索并标明来源。
- 聊天回复支持自动渲染折线图、面积图、柱状图和饼图，展示摘要指标、统计口径与来源，支持点按或键盘查看数值并切换为数据表；流程图与时序图继续使用 Mermaid。

## 1.6.0 — 鸿蒙界面与交互

- 图片识字菜单为拍照和图库添加系统图标，支持光感的窄屏设备在顶栏按钮上显示原生材质。
- 修复图片识字菜单的圆角背景丢失、文字与聊天页重叠的问题。
- 可把文字、链接、图片和文件拖进输入区，也可从回答的复制按钮拖出纯文本。
- 「设置 → 隐私」新增可选的防截屏和录屏开关。
- 快速切换设置页签时，高亮随内容立即更新，旧页签的底色不再短暂残留。
- 支持的折叠屏进入全屏悬停时，上半屏显示聊天内容，下半屏保留输入框。
- 修复悬停布局覆盖系统旋转策略，导致 Pura X Max 内屏开启旋转锁定后仍随设备转动的问题。
- 修复鸿蒙手机和平板在聊天输入框按软键盘「换行」却直接发送消息的问题。
- 修复折叠屏展开时弹出软键盘导致聊天输入框上移抖动的问题。
- 优化软键盘、输入栏、侧栏和弹窗的过渡，减少高刷新率屏幕上点按输入框和切换页面时的掉帧，宽屏来源面板滑动时保持对话内容的宽度稳定。
- 修复折叠屏展开时点按输入框，输入栏和页面内容上冲后回落的问题。

## 1.5.4 — 大图与启动器图标修复

- 同一对话沿用开始时的记忆，新记住或修改的内容从下一个对话起使用，后续轮次更容易命中 API 缓存。
- 上传长截图或大图时自动缩小上传副本并保留本地原图，继续旧对话时可自动补传超限图片。
- 修复鸿蒙桌面图标的分层和尺寸，保留原有角色和字标，由系统按场景裁切图标。

## 1.5.3 — 长附件修复

- 修复新对话上传长篇附件（如电子书或长 PDF）后提示 User input too long、无法回答的问题。
- 开启智能搜索或消息带链接时，附件内容超出联网工具的输入上限会显示中文说明。

## 1.5.2 — 页面优化

- 修复折叠屏外屏滚动设置二级页时，返回栏与开关重叠的问题。
- 「外观」「对话」「语音」加入进出过渡动效，并遵循系统的减少动态效果设置。

## 1.5.1 — 客户端体验优化

- 聊天改用 DeepSeek API 的默认内容检查，「阅读链接」可在「通用设置 → 对话」独立关闭。
- 对话设置可选择 Flash 或 V4 Pro，并调整推理强度和输出 Token 上限，涉及附件或现有联网工具时自动使用 Flash。
- 聊天附件中的 PDF、Word 和 PPT 单个可上传至 100 MiB。
- 导入历史对话可选择合并，保留已有对话并跳过同 ID 会话。
- 通用设置分为外观、对话和语音二级页，在「对话」开启「猜你想问」后，点按回答下方的建议问题即可填入草稿。
- 无痕说明随消息滚动，阅读时释放顶栏下方原先被占用的空间。

## 1.5.0 — 对话查找、分享与语音

- 从侧栏按标题或当前分支的消息搜索历史对话，点结果可跳到对应消息，结果多时可在弹窗内独立滚动。
- 鸿蒙版可用系统声音离线朗读回答，设置中仍可选 DeepSeek API 音色。
- 鸿蒙版可预览并通过系统分享面板分享单条回答或整段对话，支持纯文字、Markdown 和长图。
- 「通用设置 → 语音输入」默认使用本地识别，也可手动切换到 DeepSeek API，首次确认麦克风后即可连续按住说话，松手确认后上传录音转写。
- 优化侧栏、选择器和弹窗的键盘焦点，鸿蒙内外屏打开历史对话后点输入框才弹键盘，语音输入支持用键盘开始、结束和取消。
- 修复折叠屏内屏的角落挖孔避让导致页面偏移，以及宽屏设置页横向滑动裁字的问题。

## 1.4.2 — 聊天缩放与按住说话

- 放大页面时，正文随可见区域重新排版，顶栏与输入区保持可用。
- 调整输入框收起和展开的节奏，放慢过渡并减小突然弹出的感觉。
- 鸿蒙输入栏随窗口高度和比例调整，在矮窗、横屏和软键盘弹起时收紧。
- 鸿蒙版在输入框为空时可从右下角切到「按住说话」，松开后将识别结果保留为草稿，有文字或附件时显示发送键。
- 说话时可上滑并松手取消，录音底色铺满输入栏上半部并渐隐衔接工具栏。

## 1.4.1 — 设置滚动与输入框动效

- 优化鸿蒙设置页的触摸滚动，切换设置分组时从该页顶部开始。
- 阅读时收起或恢复输入框会平滑过渡，草稿和附件仍可继续编辑。

## 1.4.0 — 阅读、人设与 API 使用体验

- 在「通用设置」开启「阅读时隐藏输入框」后，向上翻阅聊天可收起输入框，回到底部或手动恢复时保留草稿。
- 在「个性化」中可创建、编辑和选用自定义人设卡，启用后所选人设应用于后续回答。
- 阅读时隐藏输入框与人设卡默认关闭。
- 在「数据管理」的 API Key 下方查看可用余额、充值和赠金明细，以及当前峰谷计费时段和下次切换时间。
- 长对话接近上下文上限时可查看用量，超限后可修改消息或带上草稿和附件开启新对话。

## 1.3.3 — 后台回复与通知修复

- 修复切到后台后，短时任务提前结束或回答过长时可能收不到完成通知的问题。
- 切回应用时合并后台收到的回答内容，减少后台逐段刷新带来的开销。
- 在支持的鸿蒙设备上，重新开启回答完成通知时可进入系统通知设置。

## 1.3.2 — 沉浸光感优化适配鸿蒙特性

- 开启沉浸光感时，支持的鸿蒙设备会为拍照和图库识字菜单应用系统材质，其他设备使用普通菜单。
- 原生识字菜单跟随应用的浅色、深色或跟随系统设置。
- 降低聊天输入区的模糊强度并提高底色不透明度，提升深浅主题下的可读性，在高对比度或减少透明度时使用实色背景。
- 软键盘弹起时保留输入区的底色和高光，暂时关闭背景模糊。
- 普通菜单可用方向键选择、Enter 或空格确认，按 Esc 关闭时焦点回到触发按钮。

## 1.3.1 — 配色与设置

- 默认主题色改为天蓝 #66ccff，原来的松绿保留为可选预设。
- 深色模式的背景和输入区跟随主题色，不再固定偏绿。
- 位置信息可以选择任意国家或地区，选中国时再细化到省市，并说明了用途。
- 设置中「沉浸光感」和「回答完成通知」之间增加间距和分隔线。
- 优化界面文案。

## 1.3.0 — 无痕对话与鸿蒙适配

- 新增无痕对话：不保存记录，不读取也不更新记忆，离开后自动丢弃。
- 切到后台后继续生成回答，完成时发送通知，点通知直接回到对话。
- 适配系统返回手势和系统字体大小；2in1 支持 Ctrl+N、Ctrl+B、Ctrl+, 快捷键和右键菜单。
- 修复主题设为「跟随系统」时仍显示浅色，以及键盘弹出时左上角按钮与状态栏重叠的问题。
- 修复打开侧栏时顶栏标题和图标跳动的问题。

## 1.2.1 — 宽屏居中与侧栏

- 修复平板横屏时摄像头挖孔在角落，导致欢迎页和对话整体偏左、没有居中的问题。
- 宽屏展开侧栏时，侧栏底色和分隔线延伸到状态栏和底部手势区，上下不再出现断开的色带。

## 1.2.0 — 自定义指令与记忆

- 设置新增「个性化」：填写希望 DeepSeek 了解的背景和回复偏好，用于所有对话。
- 新增跨对话记忆：每轮回答后自动记住关于你的长期信息，说「记住……」或「忘掉……」也会生效。
- 可以查看、手动添加、编辑、删除和清空记忆，「整理」可合并重复条目，并支持撤销。
- 指令和记忆分别有开关，关闭后保留内容但不发送；疑似密钥、密码和证件号不会被记住。

## 1.1.0 — 语音、识字、分享与导出

- 输入框的麦克风按钮回来了，使用系统离线语音识别，识别时实时显示文字，说完自动填入，不消耗 API 额度。
- 新增「识别图片文字」：拍照或从图库选图，在本机识别文字后插入输入框，图片不上传。
- 可以从其他应用把文字、链接、图片和文档分享到 Deepseek GO，内容会放进新对话等你确认后发送。
- 「导出所有历史对话」恢复可用，由系统文件管理器选择保存位置。

## 1.0.6 — 欢迎页与键盘过渡

- 更新启动器图标。
- 键盘弹出时，欢迎页 Logo 会等比缩小并完整显示，输入区会随键盘平滑移动。
- 设置与搜索面板开合、发送首条消息、编辑消息和思考预览收起的过渡更顺畅。

## 1.0.5 — 图标与宽屏侧栏

- 新对话欢迎页增加 Logo，并更新启动器图标。
- 修复开启沉浸光感后顶栏按钮出现蓝圈的问题。
- 宽屏侧栏支持滑动开合，聊天区会随之调整宽度。

## 1.0.4 — 深度思考与消息编辑

- 深度思考只预览最新几行，开始回答后自动收起，可点标题展开全文。
- 编辑历史消息时暂时隐藏主输入栏，保留输入草稿，并让取消和发送按钮避开键盘。
