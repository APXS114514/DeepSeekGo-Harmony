# Roadmap

[简体中文](ROADMAP.md)

These features are planned roughly in this order. They are not yet assigned to releases, and the plan may change.

1. **Search past chats**: find earlier conversations by title or content.
2. **On-device read-aloud**: read answers offline with the system voice, without the API and with less delay. You can choose it or the existing API voices.
3. **Share out**: send an answer or a whole conversation to other apps as text, Markdown, or a long image, complementing "Share to Deepseek GO".
4. **Accessibility**: add button labels and a logical focus order for screen readers, and check readability in high contrast.
5. **Home screen widget**: start a question or open a recent conversation from the home screen.
6. **Drag and drop**: on tablet split screen or 2in1, drag text, images, and files into the input box, or drag an answer into another app.
7. **Foldable hover mode**: when half-folded on a desk, show the answer on the upper half and type on the lower half.
8. **Cross-device continuation**: pick up a chat on a tablet or PC where you left off on your phone, draft included.

For released features, see [Features](FEATURES.en.md).
