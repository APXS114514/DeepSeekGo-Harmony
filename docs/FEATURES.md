# 功能说明

[English](FEATURES.en.md)

介绍 Deepseek GO 当前版本的全部功能。各版本的变化见 [更新日志](CHANGELOG.md)。

## 对话

- 流式回复、多轮对话、编辑历史消息并重新生成，可在不同回答版本之间切换。
- **撤回上一轮**：在最新一条提问上撤回该轮提问和回答，正在生成时先停止。提问和附件恢复为可编辑的草稿，该轮不再计入本机记录和后续上下文。
- **对话分支**：在回答上选择「从此处开启新分支」，新建一个包含开头到该回答的独立对话。原对话和分支在侧栏自动归入可折叠的对话组，各自可以继续、重命名和删除。
- **聊天模型**：在「通用设置 → 对话」选择 Flash 或 V4 Pro，含附件或使用现有联网工具的请求自动使用 Flash。
- **深度思考**：思考时只预览最新几行，开始回答后自动收起，点标题可展开全文。「通用设置 → 对话」可调整推理强度和输出 Token 上限。
- **智能搜索**：联网搜索并标注来源，宽屏时来源卡片在右侧并排显示。「通用设置 → 对话」可单独开启或关闭阅读链接。
- **当地信息查询**：结合城市与当地日期自动查询天气、活动和营业时间并在回答中标明来源；逐日天气优先获取 Open-Meteo 结构化数据，其余本地问题或接口不可用时自动联网搜索。查询汇率、行情等实时数据但未开启智能搜索时，回答区会提示并提供一键开启入口。可在「通用设置 → 对话」关闭自动查询当地信息。
- **猜你想问**：在「通用设置 → 对话」手动开启后，应用会额外调用 API，为当前对话的新回答生成最多三条相关问题。点按将问题填进草稿，可修改后再发送。
- Markdown、代码高亮、数学公式、交互式数据图表（折线图、面积图、柱状图、饼图，含摘要指标、统计口径、来源、点按查值与「图表 / 数据表」切换，不显示原始代码；可在「通用设置 → 对话」通过「主动生成图表」开关控制由模型自行决定何时画图或仅按要求生成）和 Mermaid 图表，回答可复制或朗读。
- **搜索历史对话**：在侧栏搜索标题或当前分支的消息，选择结果可打开对应对话或定位到消息。
- 上传图片、PDF、Office 文档和代码等附件。PDF、Word 和 PPT 单个最大 100 MiB，图片 64 MiB，纯文本、表格和电子书 32 MiB。
- **无痕对话**：在新对话页打开「无痕对话」，对话不保存到历史记录，也不读取或更新记忆，离开后自动丢弃。无痕说明位于消息列表开头，可随消息滚出屏幕。

## 鸿蒙版独有

- **语音输入**：按住说话，松手后填入草稿，上滑松手取消。在「通用设置 → 语音」可选默认的鸿蒙系统离线识别，或支持更多语言的 DeepSeek API。选择 API 后，录音在松手确认时上传并按时长计费。
- **本机朗读**：支持的设备可在「通用设置 → 语音」选择本机离线朗读，也可选择 DeepSeek API 的声音。
- **分享回答或对话**：从回答操作栏或会话菜单打开分享预览，把单条回答或当前对话分支以纯文字、Markdown 或长图分享到其他应用。
- **识别图片文字**：拍照或从图库选图，在本机识别文字后插入输入框，图片不会上传，原生菜单用系统图标区分相机和图库。
- **分享到 Deepseek GO**：在任意应用中选择「分享 → Deepseek GO」，文字、链接、图片和文档会放进新对话，由你确认后再发送。
- **导入和导出聊天记录**：在 **设置 → 数据管理** 中将对话导出为 ZIP，或将 ZIP 合并到本地历史。合并时保留现有同 ID 对话，也可选择覆盖全部记录。
- **后台生成与完成通知**：切到后台后继续生成回答，完成时发送系统通知，点通知直接回到对应对话。可在「通用设置 → 对话」关闭完成通知。
- **按需自动定位**：「通用设置 → 位置信息」改为单个定位开关，不再需要手动填写地区；开启后仅在前台处理「我这里」「附近」等本地问题时调用鸿蒙模糊定位并在本机转换为城市和行政区，不向模型发送精确坐标。
- **系统触感反馈**：按住说话、上滑取消、回答首字到达、深度思考完成、复制成功和菜单弹出时提供系统预置触感，遵循系统的触感设置。
- **桌面快捷方式**：长按桌面应用图标，可直达新对话、语音提问、识别图片文字或无痕对话。
- **API Key 安全存储**：Key 保存在鸿蒙系统的 Asset Store 中，不写入网页存储。

本机语音和识字依赖设备的系统 AI 能力。可用入口随设备能力和语音设置变化。

## 个性化与记忆

在 **设置 → 个性化** 中：

- **自定义指令**：填写「希望 DeepSeek 了解你的哪些背景」和「希望 DeepSeek 怎样回复」，保存后对所有对话生效。
- **跨对话记忆**：每轮回答结束后，模型会从你的话里提炼值得长期记住的信息，例如职业、长期目标和偏好，以后的对话会自然地参考这些信息。在对话中说「记住……」或「忘掉……」同样有效。新记住或修改的内容从下一个对话开始使用，删除的记忆立即停用。
- **管理记忆**：可以查看、手动添加、编辑、删除和清空记忆。「整理」会让模型合并重复和过时的条目，不满意可以撤销。
- 指令和记忆各有开关，关闭后内容保留但不再发送。疑似密钥、密码、证件号的内容不会被记住。

自动记忆每轮会额外发送一次很小的请求，消耗少量 Token，不需要时可以在设置里关闭。

## 多设备与界面

- 同一个安装包适配手机、折叠屏、平板和 2in1，布局随窗口宽度变化，跨断点时保留当前会话和草稿。
- 窄屏使用滑动抽屉，宽屏常驻侧栏，收起或展开时聊天区平滑伸缩。
- 背景延伸到状态栏和手势区，内容自动避让状态栏、挖孔和键盘。
- 浅色、深色或跟随系统，主题色可选预设、拾色或输入十六进制颜色。
- 系统返回手势逐级关闭菜单、弹窗、设置、搜索面板和侧栏，没有可关闭的内容时才离开应用。
- 回答、消息和输入框的文字跟随系统字体大小，最大 1.75 倍。
- 2in1 支持快捷键：`Ctrl+N` 新对话、`Ctrl+B` 收起或展开侧栏、`Ctrl+,` 打开设置。右键或触屏长按会话可以打开重命名、分享和删除菜单。
- **沉浸光感**：输入区、悬浮按钮和胶囊开关带有半透明和高光。支持系统材质的设备上，窄屏顶栏按钮带按压形变、流光和图标动效，会话菜单、图片识字菜单、附件与工具半模态以及删除、清空确认弹窗使用原生光感样式。可在「通用设置 → 外观」关闭。
- **分屏拖拽**：可将文字、链接、图片和文件拖入输入区，或拖动回答的复制按钮将纯文本带到其他应用。
- **折叠屏悬停**：支持的设备在全屏悬停时，上半屏显示聊天，下半屏用于输入，展开后继续当前会话和草稿。
- 动效遵循系统的「减少动态效果」设置。侧栏、历史搜索、设置和分享支持键盘导航，语音模式下可用 Enter 或空格开始和结束录音，用 Esc 取消。

## 隐私

- **防截屏和录屏**：可在「设置 → 隐私」开启，让系统在截屏、录屏、投屏和多任务预览中保护聊天窗口。
- 对话、草稿、指令和记忆都只保存在本机。
- 应用只与 `api.deepseek.com` 及结构化天气查询接口（`open-meteo.com`）通信，内置页面使用严格的内容安全策略，外部链接交给系统浏览器打开。
- 代码、安装包和日志中都不包含 API Key。
